# usage-meter

A Claude Code mod that shows your Claude usage above the prompt. On the desktop app it draws a slim row of liquid-filled capsules for your 5-hour limit, weekly limit, context window and session cost. The capsules update by themselves and animate while Claude works. In a terminal it draws a text band instead.

Type `/meter` to hide or show it.

The desktop layout is sized for a 768px chat box on the dark theme.

## Install

At the prompt of a terminal session:

```
/plugin install usage-meter --marketplace Gautham-SG/usage-meter
```

From a shell:

```
claude plugin install usage-meter --marketplace Gautham-SG/usage-meter
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `Gautham-SG/usage-meter`, then Add plugin.
